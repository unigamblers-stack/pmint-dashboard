# pMINT Dashboard

Live stats and long-term projections for pMINT mining on PulseChain.

Mining Contract: `0xA54E7486Dc69219B6814798b30dd09e14Ee9cd10`

## Features
- Real-time data pulled straight from the blockchain
- Current cycle status and mint cost
- Supply tracking and burn metrics
- Future halving projections

## Project Structure
src/ ├── config.py ├── data_fetcher.py ├── projections.py ├── charts.py main.py requirements.txt

## Setup
1. Clone the repo
2. `pip install -r requirements.txt`
3. Run `python main.py`

Built with web3.py for PulseChain.
